# Power spectrum Cls

Here you can find the power spectrum Cls measured from the box. \

All the Cls were computed from the sources output of the box. 
Those were then projected onto a healpy map with resolution $\text{NSIDE}=512$.

You can also find tomographic redshift bins of some of the power spectra measured. \
\
$ \text{Bin0:} \quad  0 < z \leq 2.0 $ \
$ \text{Bin1:} \quad  2.0 < z \leq 3.8 $
