# CoLoRe simulation CMB $\kappa$ values

CMB lensing convergence $\kappa$ values of the first test box from the [CoLoRe simulation](https://github.com/damonge/CoLoRe). The source plane is the standard  last scattering surface of the CMB.

- $z_{\rm max} = 3.8$

- $z_* = 1100$
