# CoLoRe additional files

In order to run CoLoRe boxes, apart from the linear power spectrum, the quasars redshift distribution and the quasar bias parameter evolution are also needed.

- File [Nz_qso_130618_2_colore1_hZs.txt](../Nz_qso_130618_2_colore1_hZs.txt) contains the quasars redshift distribution n(z).
- File [Bz_qso_G18.txt](../Bz_qso_G18.txt) contains the quasar bias parameter b_Q(z) evolution with redshift.

## Running CoLoRe in NERSC

Moreover, to run CoLoRe in NERSC, one has to modify the [Makefile](Makefile) complying with NERSC installation. Here you can find the right Makefile to do this. In addition to this, I will be soon uploading a pdf on instructions to install CoLoRe and its dependencies in your NERSC allocation.
