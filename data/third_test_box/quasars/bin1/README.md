# Tomographic Redshift Bin 1

This folder contains all products associated with the first quasar tomographic bin.

## Redshift range

$$
1.5 < z \leq 3.8 \ (z_{\rm max} \rm \ of\  CoLoRe)
$$

Notes:
- Lower edge is exclusive and upper edge is inclusive.
- Files in this directory correspond exclusively to objects within this redshift interval.
